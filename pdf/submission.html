THE IMPORTANT INVARIANT

After failure: order = [Scene 2, Scene 1]; Scene 2 script = revised; Scene 2 duration = 3 seconds; Scene 1 = original approved image (5 seconds). Export stays disabled until Scene 2 has approved media.

01  Script
Scene text and media mode are editable; revisions belong to the scene, not to its job.
02  Sequence
Drag or arrows reorder. +/− trims playback. Neither change restarts generation.
03  Recovery
Failure is inline on Scene 2: Retry / Replace. Approval alone unlocks export.
Walkthrough revision: I replaced a transient error toast with a persistent, scene-level recovery card so the next action is obvious.

Retry failed scene  /  pseudocode (18 lines)
async function retry(sceneId, failedJobId) {
  const scene = store.scenes[sceneId];
  const old = store.jobs[sceneId];
  if (old.id !== failedJobId || old.status !== "failed") return;
  const input = { script: scene.script, kind: scene.mediaType };
  const revision = scene.contentRevision;  // not order/trim
  const key = uuid();  // deduplicates rapid retries
  store.setJob(sceneId, { id: key, status: "submitting" });
  try {
    const job = await api.createGeneration({
      sceneId, input, revision, idempotencyKey: key });
    if (store.jobs[sceneId].id !== key) return;
    store.setJob(sceneId, { ...job, revision });
  } catch (error) {
    if (store.jobs[sceneId].id === key)
      store.setJob(sceneId, { id: key, status: "failed", error });
  }
} // Never mutate script, duration, order or approvedAssetId.
What ships first

Scene cards, not a full timeline. For marketers, drag-to-reorder and a duration stepper are faster to understand and implement. Tradeoff: no frame-accurate cuts, layered audio or keyframes in v1.

State, component, export

Persist project.sceneOrder and scene edits server-side (optimistic UI with revision checks). Build SceneCard first as the interaction + status vertical slice. Export only if every included scene has a user-approved, ready asset.

One observable usability test

Ask five marketers to reorder/trim during generation, then resolve a failure. Pass: ≥4/5 finish in 2 minutes without redoing edits and correctly explain why export is locked.
